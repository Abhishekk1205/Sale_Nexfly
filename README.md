# NaviDron (Sale_Nexfly) 🚁

**NaviDron by Nexfly Robotics** — Premium Custom Drones, 3D Prints, and GTA 6 Streetwear & Collectibles in official collaboration with YouTuber **P_Brothers (Priyanshu)**.

---

## ⚡ Tech Stack & Architecture

- **React 18** with **Vite 6**
- **React Router 6** for separate modular routing
- **Lucide React** & **Canvas Confetti** for interactive feedback
- **Modular Directory Architecture**:
  - `src/components/Navbar/` — Floating glassmorphic navbar with category dropdowns & mobile menu
  - `src/components/Footer/` — Responsive footer with newsletter subscription & social channels
  - `src/pages/Home/` — Dynamic animated landing page, live counters, floating drone, and big-screen P_Brothers promo
  - `src/pages/UAV/` — FPV Racing, Agricultural Hexacopters, Toy, College Projects, and RC Planes
  - `src/pages/Prints/` — 3D printed action figures (GTA 6, Valorant, Anime), lithophanes, and gift packs
  - `src/pages/PBrothers/` — Dedicated collaboration hub with video breakdowns, GTA 6 figures, and graphic streetwear T-Shirts
  - `src/pages/Products/` — Drone parts, electronic stacks, and 3D printed TPU accessories
  - `src/pages/Gallery/` — Filterable visual showcase with lightbox zoom preview
  - `src/pages/Services/` — Engineering workflows, custom manufacturing, repair, and CAD services
  - `src/pages/Contact/` — Interactive quote and contact form with WhatsApp integration

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) to view in your browser.

### 3. Production Build
```bash
npm run build
```
